## English

Welcome to 翻车 of the week. Each note is a real pattern from the AgentFails catalog, with the page that holds the copy-paste fix.

This first issue samples the catalog's three questions: did it build the right thing, is it bug-free, and did it stay in bounds? The split comes from [@liushiyumath's thread](https://x.com/liushiyumath/status/2111233400346710364).

### 1. "All tests pass" (nothing was run) · Bug

The agent says the work is done or passing without having executed the check that would prove it.

- English: https://agent-fails.vercel.app/patterns/phantom-success
- 中文: https://agent-fails.vercel.app/zh/patterns/phantom-success

### 2. A stub shipped as "done" · Wrong feature

The agent reports the feature complete, but a function body is `pass`, `return null`, or `throw new Error("not implemented")`.

- English: https://agent-fails.vercel.app/patterns/placeholder-shipped-as-done
- 中文: https://agent-fails.vercel.app/zh/patterns/placeholder-shipped-as-done

### 3. Built what it understood, not what you meant · Wrong feature

The agent ships a coherent feature that answers a different reading of the request. Every check passes, because the checks test the agent's reading too.

- English: https://agent-fails.vercel.app/patterns/spec-misread
- 中文: https://agent-fails.vercel.app/zh/patterns/spec-misread

### 4. Imported a package that doesn't exist · Bug

The agent imports or installs a plausibly named package that isn't in your manifest, or doesn't exist at all. A squatted name makes this a supply-chain risk.

- English: https://agent-fails.vercel.app/patterns/hallucinated-package
- 中文: https://agent-fails.vercel.app/zh/patterns/hallucinated-package

### 5. Asked for one fix, it changed unrelated files · Overreach

You asked for one change; the diff also "cleaned up" other functions, files and configs nobody mentioned.

- English: https://agent-fails.vercel.app/patterns/unrelated-files-changed
- 中文: https://agent-fails.vercel.app/zh/patterns/unrelated-files-changed

Full catalog: https://agent-fails.vercel.app

## 中文

欢迎来到每周翻车。每条都是智能体翻车库里的真实模式，链到带可复制修复的页面。

这一期按库里的三个问题抽样：做的是对的东西吗、有没有 bug、有没有越界。这个分法来自 [@liushiyumath 的帖子](https://x.com/liushiyumath/status/2111233400346710364)。

### 1. “测试全部通过”（其实一个都没跑）· 有 Bug

智能体说已经完成或测试通过，但根本没有执行能证明这一点的检查。

- 中文: https://agent-fails.vercel.app/zh/patterns/phantom-success
- English: https://agent-fails.vercel.app/patterns/phantom-success

### 2. 桩代码冒充“已完成” · 做错了功能

智能体说功能做完了，但某个函数体其实是 `pass`、`return null` 或 `throw new Error("not implemented")`。

- 中文: https://agent-fails.vercel.app/zh/patterns/placeholder-shipped-as-done
- English: https://agent-fails.vercel.app/patterns/placeholder-shipped-as-done

### 3. 按自己的理解做了，不是你要的那个 · 做错了功能

智能体交付了一个自洽的功能，但回答的是需求的另一种读法。所有检查都通过了，因为检查测的也是它自己的理解。

- 中文: https://agent-fails.vercel.app/zh/patterns/spec-misread
- English: https://agent-fails.vercel.app/patterns/spec-misread

### 4. 引入了一个根本不存在的包 · 有 Bug

智能体导入或安装了一个名字很像真的包，它不在你的依赖清单里，甚至根本不存在。如果这个名字被人抢注，就成了供应链风险。

- 中文: https://agent-fails.vercel.app/zh/patterns/hallucinated-package
- English: https://agent-fails.vercel.app/patterns/hallucinated-package

### 5. 只让修一处，它改了一堆无关文件 · 越界 / 不理想

你只要求改一处；diff 里却顺手“清理”了没人提过的其他函数、文件和配置。

- 中文: https://agent-fails.vercel.app/zh/patterns/unrelated-files-changed
- English: https://agent-fails.vercel.app/patterns/unrelated-files-changed

全部条目: https://agent-fails.vercel.app/zh
