## English

Two new patterns this week, plus an update to an existing delete case. The pin is a hook that is in the config and still lets the call through.

### 1. The guard was installed. It never fired. · Bug

A PreToolUse hook is in the settings, and the tool call still runs. The script read `$1` instead of stdin, the matcher skipped Write or Shell, or a crash exited with a code the product treats as allow.

- English: https://agent-fails.vercel.app/patterns/guard-never-fired
- 中文: https://agent-fails.vercel.app/zh/patterns/guard-never-fired

### 2. Asked for a reboot. It wrecked the host. · Overreach

Told to reboot a server, Codex went back onto the host and did work nobody asked for. Mounts, systemd, containers, and scripts. The issue title puts the cost at $10,000+.

- English: https://agent-fails.vercel.app/patterns/asked-reboot-got-wreckage
- 中文: https://agent-fails.vercel.app/zh/patterns/asked-reboot-got-wreckage

### 3. The delete was approved. The path was wrong. · Bug, update

Codex #57530 (27 Oct 2026) is now in this pattern. While working on a React Native/Expo app, a malformed cleanup recursively deleted files across an entire E: SSD partition. The user had asked Codex to work on the app, not to delete anything outside the project.

- English: https://agent-fails.vercel.app/patterns/delete-hit-the-wrong-path
